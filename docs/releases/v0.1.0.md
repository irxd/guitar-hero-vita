# GH Vita v0.1.0 (alpha)

The first public build of GH Vita, a homebrew PS Vita port of Guitar Dream Engine's
reimplementation of Guitar Hero (PlayStation 2, 2005).

Based on Guitar Dream Engine, https://github.com/mbracali/prj-gd-engine
(gd01 1.1.13). Not affiliated with or endorsed by the Guitar Hero trademark owners or the
Guitar Dream Engine maintainer.

This is an **alpha**: songs are fully playable, but some modes are untested and there will be bugs.

## What you need

- A hacked PS Vita or PS TV (HENkaku / h-encore / Ensō).
- `libshacccg.suprx` extracted on the console (for example with ShaRKBR33D). The game
  compiles its shaders at run time and cannot start without it.
- **Your own** Guitar Hero PS2 disc, ripped to an `.iso`. Tested with *Guitar Hero (USA)*.
  No game data is included, and none will be provided.

## Install

1. Install `ghvita-v0.1.0.vpk` with VitaShell.
2. Copy your `.iso` to `ux0:data/ghvita/` (create the folder if needed).
3. Start **GH Vita** from the LiveArea.

Settings, saves and the log are stored in `ux0:data/ghvita/` too.

If you installed a test build before: delete its old *GH Vita* bubble. The title ID is now
`GHVT00001`. Your `ux0:data/ghvita/` folder (ISO, saves, settings) is kept.

## Controls

| | Green | Red | Yellow | Blue | Orange | Strum |
|---|---|---|---|---|---|---|
| Layout 1 (default) | D-pad ← | L | R | ○ | ✕ | D-pad ↑/↓ |
| Layout 2 | D-pad ← | D-pad ↑ | △ | ○ | ✕ | L / R |

- A fret press plays the note on its own, so strumming is optional. A strum while you hold
  frets plays them again, which helps with fast runs of one note or chord. With the default
  settings a strum never counts as a miss (turn on Require Strum on the Gamepads screen to
  play with strict guitar rules instead).
- Whammy: either analog stick. Star Power: Select. Pause: Start.
- Change the layout under Options → Enhanced Settings → Button Layout. Single buttons can be
  rebound on the Gamepads screen.
- Optional, in Enhanced Settings:
  - **Rear Touch Strum**: tap the rear touchpad to strum. Hold the fret and drum two fingers
    on the back for fast runs of one note.
  - **Shake for Whammy**: shake the Vita to use the whammy.

## Performance

Under Options → Enhanced Settings → Performance & Graphics:

- **30 FPS** (default): a steady 30 FPS with the full stage, band and crowd.
- **60 FPS**: about 46 FPS on average with the crowd (the widest crowd shots drop into
  the 30s), or 47–58 FPS with Crowd off.
- **Notes Only**: just the highway, a locked 60 FPS, with faster loading.

## Known issues

- Not tested yet: Career mode, tutorials, and two-player face-off (it needs a second controller).
- No post-processing effects (bloom, depth of field) and no fade at the far end of the highway.
- Rarely, the first start after installing stops on a black screen. Close the app and start it again.

## Reporting bugs

Attach `ux0:data/ghvita/ghvita.log` from the run where it happened, and say which song and
settings you used. Do not post screenshots or files that contain game data.
