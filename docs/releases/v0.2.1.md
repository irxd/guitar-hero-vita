# GH Vita v0.2.1 (alpha)

A bug-fix build of GH Vita, a homebrew PS Vita port of Guitar Dream Engine's
reimplementation of Guitar Hero (PlayStation 2, 2005).

Based on Guitar Dream Engine, https://github.com/mbracali/prj-gd-engine
(gd01 1.1.13). Not affiliated with or endorsed by the Guitar Hero trademark owners or the
Guitar Dream Engine maintainer.

This is an **alpha**: songs are fully playable, but some modes are untested and there will be bugs.

## Changes since v0.2.0

- **Only Start pauses a song.** Pressing ○ paused the song before the first notes
  appeared, and in Button Layout 3 (where ○ is not a fret) at any time. Now only Start
  (or the on-screen pause button) pauses; ○ still works as Back in the menus.

To update, install the new VPK over v0.2.0 (or any earlier version). Your
`ux0:data/ghvita/` folder (ISO, saves, settings) is kept.

For everything new in v0.2.0 (60 FPS default, Button Layout 3, rear touchpad buttons,
L2 / R2, new LiveArea), see the v0.2.0 release notes.

## What you need

- A hacked PS Vita or PS TV (HENkaku / h-encore / Ensō).
- `libshacccg.suprx` extracted on the console (for example with ShaRKBR33D). The game
  compiles its shaders at run time and cannot start without it.
- **Your own** Guitar Hero PS2 disc, ripped to an `.iso`. Tested with *Guitar Hero (USA)*.
  No game data is included, and none will be provided.

## Install

1. Install `ghvita-v0.2.1.vpk` with VitaShell.
2. Copy your `.iso` to `ux0:data/ghvita/` (create the folder if needed).
3. Start **GH Vita** from the LiveArea by tapping the lettering.

Settings, saves and the log are stored in `ux0:data/ghvita/` too.

## Controls

| | Green | Red | Yellow | Blue | Orange | Strum |
|---|---|---|---|---|---|---|
| Layout 1 (default) | D-pad ← | L | R | ○ | ✕ | D-pad ↑/↓ (optional) |
| Layout 2 | D-pad ← | D-pad ↑ | △ | ○ | ✕ | L / R (optional) |
| Layout 3 (PS2) | L2 / rear left | L | R | R2 / rear right | ✕ | D-pad ↑/↓ (optional) |

- A fret press plays the note on its own, so strumming is optional. A strum while you hold
  frets plays them again, which helps with fast runs of one note or chord. With the default
  settings a strum never counts as a miss (turn on Require Strum on the Gamepads screen to
  play with strict guitar rules instead).
- Whammy: either analog stick. Star Power: Select. Pause: Start.
- An external controller (a DualShock or DualSense through ds34vita) plays alongside the
  Vita's own buttons: both control player 1.
- Change the layout under Options → Enhanced Settings → Button Layout. Single buttons can be
  rebound on the Gamepads screen, including the rear touchpad halves.
- Optional, in Enhanced Settings:
  - **Rear Touch Strum**: tap the rear touchpad to strum. Hold the fret and drum two fingers
    on the back for fast runs of one note. A half of the touchpad that is bound to a control
    (as in Layout 3) plays that control instead.
  - **Shake for Whammy**: shake the Vita to use the whammy.

## Performance

Under Options → Enhanced Settings → Performance & Graphics:

- **60 FPS** (default) with **Crowd** off (default): 59.9 FPS.
- **60 FPS** with the crowd on: about 56 FPS on average; the widest crowd shots drop to about 47.
- **30 FPS**: a steady 30 FPS with the full stage, band and crowd.
- **Notes Only**: just the highway, a locked 60 FPS, with faster loading.

## Testing so far

- Partly tested: Career mode, tutorials, the Gamepads screen.
- Not yet tested: L2 / R2 on a PS TV with a DualShock.

## Known issues

- **Two-player (face-off) is not supported yet.** With two DualSense controllers on
  ds34vita, the second one stops responding after a while (on the main menu or while
  characters load) and only comes back after Bluetooth is restarted. It is not yet clear
  whether this is a ds34vita limit or the port.
- A black screen while loading the next song was reported once (v0.1.0). If it happens to
  you, please attach `ghvita.log`: it now shows the memory use at each song load.
- No post-processing effects (bloom, depth of field) and no fade at the far end of the highway.
- Rarely, the first start after installing stops on a black screen. Close the app and start it again.

## Reporting bugs

Open an issue with the bug report form
(https://github.com/irxd/guitar-hero-vita/issues/new/choose) and attach
`ux0:data/ghvita/ghvita.log` from the run where it happened. Do not post screenshots or files that contain game data.
